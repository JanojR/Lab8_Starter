## Question Answer:  
Graceful degradation and Service Workers are related because Service Workers in essence enable graceful degradation in an app when network conditions aren't perfect. When the user has internet and the browser supports service workers, the service workers can get the latest resources and give the best possible experience. However, when network isn't available, the app can return cached files and data instead of completely failing. Further, if service workers aren't supported at all, it won't completely fail the site since they are essentially multithreading (the main thread for the actual site isn't blocked).
